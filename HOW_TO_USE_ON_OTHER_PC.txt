    POCKETO POS - HOW TO USE ON OTHER COMPUTERS
═══════════════════════════════════════════════════════════════

✅ YOUR POS IS NOW PORTABLE!

You can copy it to any Windows PC and use it there.

═══════════════════════════════════════════════════════════════
📦 WHAT TO COPY
═══════════════════════════════════════════════════════════════

Copy the ENTIRE "POCKETO_POS" folder to:
- USB Drive
- External Hard Drive  
- Google Drive / Dropbox
- Network Share
- Another PC directly

Your folder contains:
✓ backend/         (Python server)
✓ frontend/        (React website)
✓ data/            (Your orders database - IMPORTANT!)
✓ FINAL_START.bat  (Starts POS)
✓ SETUP_NEW_PC_SIMPLE.bat (Setup on new PC)
✓ All other files

═══════════════════════════════════════════════════════════════
🖥️ METHOD 1: USB DRIVE (EASIEST)
═══════════════════════════════════════════════════════════════

ON YOUR CURRENT PC:
------------------
1. Copy entire POCKETO_POS folder to USB drive
2. Wait for copy to complete (may take 5-10 minutes)
3. Safely eject USB

ON THE NEW PC:
--------------
1. Plug in USB drive
2. Copy POCKETO_POS folder to Desktop (or anywhere)
3. Open the POCKETO_POS folder

4. FIRST TIME ONLY - Install these 3 programs:
   a) Python: https://www.python.org/downloads/
      ⚠️ CHECK "Add Python to PATH" during install!
   
   b) Node.js: https://nodejs.org/
      (Download LTS version, install with defaults)
   
   c) MongoDB: https://www.mongodb.com/try/download/community
      ⚠️ CHECK "Install as Service" during install!

5. After installing above, double-click: SETUP_NEW_PC_SIMPLE.bat
   (This takes 15-20 minutes, wait for "Setup Complete")

6. From now on, just double-click: FINAL_START.bat
   (Your POS opens in browser!)

═══════════════════════════════════════════════════════════════
🌐 METHOD 2: GOOGLE DRIVE / DROPBOX
═══════════════════════════════════════════════════════════════

1. Put POCKETO_POS folder in Google Drive
2. Install Google Drive on new PC
3. Wait for folder to sync
4. Follow steps 4-6 from Method 1 above

═══════════════════════════════════════════════════════════════
🏢 METHOD 3: NETWORK SHARE (Multiple PCs in same location)
═══════════════════════════════════════════════════════════════

1. Put POCKETO_POS in network shared folder
2. Access from any PC on same network
3. On each PC, run SETUP_NEW_PC_SIMPLE.bat once
4. Then use FINAL_START.bat daily

═══════════════════════════════════════════════════════════════
⚡ DAILY USAGE ON ANY PC
═══════════════════════════════════════════════════════════════

Every Day:
1. Double-click FINAL_START.bat

3. Browser opens with your POS
4. Start taking orders!

End of Day:
1. Close browser
2. Close the 3 command windows

To backup:
- Copy entire POCKETO_POS folder (includes data)

═══════════════════════════════════════════════════════════════
🔧 TROUBLESHOOTING ON NEW PC
═══════════════════════════════════════════════════════════════

Problem: "Python not found"
Solution: Install Python, CHECK "Add to PATH"

Problem: "Node not found"  
Solution: Install Node.js

Problem: "MongoDB not found"
Solution: Install MongoDB as Service

Problem: "Port already in use"
Solution: Restart PC, try again
